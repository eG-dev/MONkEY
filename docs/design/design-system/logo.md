# Logo

Status: Approved by the user on 2026-10-10.

## Assets

| Asset | Use |
| --- | --- |
| [monkey.png](../assets/images/monkey.png) | Wordmark with the monkey face as the "O" (531 x 96) |
| [monkey_face.png](../assets/images/monkey_face.png) | Square face mark, for example a favicon or very narrow layouts (384 x 384) |

Use the supplied files rather than recreating the wordmark as text. The lowercase
"k" in maroon is part of the product name and must stay recognizable.

## Usage

- Preserve the aspect ratio. Do not stretch, recolor, rotate, or add effects.
- Place the wordmark in the toolbar immediately after the hamburger. Opening or
  closing navigation must not move it.
- Give the logo the text alternative "POCKET MONkEY" unless adjacent text already
  names the product.
- Do not add a splash screen solely to display the logo.

## Open Issue: Dark Toolbar

The logo combines peach (`#E5BFA7`) and maroon (`#650000`). On the dark-grey
toolbar, the maroon "k" and the face outline have a contrast of 1.0:1 and are
hard to make out; on white, the peach letters have only 1.7:1. No single background
gives both colors 3:1. Before approval, choose one of:

- a dark-background variant of the wordmark, for example with a light "k" and
  face outline (preferred);
- a light, rounded backdrop behind the logo inside the toolbar;
- a lighter toolbar.

The [prototype](../prototypes/application-shell/index.html) shows the unchanged
logo so the issue stays visible.
