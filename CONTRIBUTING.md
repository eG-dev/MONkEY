# Contributing to POCKET MONkEY

Thank you for taking an interest in this project.

POCKET MONkEY is a personal, spare-time revamp of an application I built several
years ago. GitHub Copilot is heavily involved in its development, and this new
version would not be possible without it. I remain responsible for the project's
direction and decisions.

## Feedback and Bug Reports

I am not actively seeking outside code contributions or relying on them to keep
development moving. Feedback, bug reports and suggestions are welcome, though,
and there is no expectation to contribute code.

Please use GitHub Issues for reproducible bugs and ideas. For a bug, include the
version, relevant configuration and steps to reproduce it, without passwords,
authentication tokens or private financial data. This is a hobby project, so
response times and implementation of suggestions cannot be guaranteed.

## Proposed Code Changes

If you would like to contribute code, please open an issue to discuss the change
before investing time in a pull request. This helps us agree on whether it fits
the project's scope and avoids work that I may not be able to accept or maintain.

For agreed changes, follow the [development guide](docs/development.md) and the
applicable repository instructions and architecture decisions. Keep the change
focused and include the relevant verification results with the pull request.
